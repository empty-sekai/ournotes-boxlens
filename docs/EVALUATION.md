# 验收与指标

模型、数据和许可边界见 [模型卡](MODEL_CARD.md)、[数据卡](DATA_CARD.md) 与 [资源边界](ASSET_BOUNDARY.md)。可复核的精简指标在 `reports/`，不含截图或逐图调试产物。

## 评估方法

`python -m bdon_vision.evaluate_engine --data DATA --set NAME=DIR --output OUT.json` 对 `Engine.scan` 做端到端评估，只依赖扫描输出契约：

- 每张截图的真值卡（图库卡 `cards` 和图库外卡面 `foreign_cards`）与输出卡框（`cards` 和 `unidentified` 都参与）按 IoU≥0.5 一对一配对；未配对、也不与忽略区域重叠的输出计为多余检测。
- 图库卡的身份分为正确、错误和未识别（进入 `unidentified`）；图库外卡面必须进入 `unidentified`，被赋予任何 ID 都算误接受。
- 等级、特训次数和卡阶：列表显示该字段、且读取区域（参数框或整个卡阶图标）完整位于截图内时为可见目标，分为正确、错误和未知；对不可见目标输出值时，与卡片真实状态不同即计为误读。
- 结果按卡类、语言、参数视图、屏幕原始分辨率、卡片宽度、图库外卡面、训练外身份、遮挡和部分出屏分层。

### 分层结果

- 部分出屏的卡（约占 12%–13%）身份召回约 77%，其余多数进入 `unidentified`；被浮层遮挡的卡身份召回约 75%。这两类都没有身份错误。
- 卡片宽度 60–119 px 的小卡身份召回约 96%，等级覆盖率 89%–93%，低于大卡。
- 英文界面的特训次数覆盖率较低（81%–88%），其他语言为 96%–99%。
- 逐语言、分辨率、参数视图和卡片宽度统计见 `reports/acceptance/holdout-full-screen.json`。

零误读只描述这些测试中已输出的值，不等于对任意输入都正确。

## 真实截图回归

8 张真实截图来自同一玩家、同一设备的一批成员与留影列表：身份 129/129（成员 120、留影 9），可见特训次数 18/18，可见卡阶 99/99，没有错误字段、多余检测或未识别卡框。这批截图中没有完整位于画面内的可见等级。它们只用于回归，不是独立真实用户测试；汇总见 `reports/acceptance/real-sample-regression.json`，原始图片不随公开包发布。

## 新卡接入

`scripts/verify_gallery_update.py` 在独立目录里从图库移除指定身份，确认这些卡进入 `unidentified`；再加回其目录条目和卡面，确认重新识别，并检查模型文件哈希不变。它是集成检查，不是独立准确率；使用方法见 [NEW-CARDS.md](NEW-CARDS.md)。

## 使用边界

渐隐、浮层或大面积遮挡可能让身份或字段变成未知，也可能造成误读。遇到遮挡请调整位置后重截，并检查或手工校对，不依赖模型还原被遮住的值。
