# 验收与指标

公开版本使用已选定的训练权重，修正留影卡面的显示窗口坐标，并修正合成拼接以保留透明外边距；没有为此重训，也没有把遮挡实验加入发布推理策略。模型、数据和许可边界见 [模型卡](MODEL_CARD.md)、[数据卡](DATA_CARD.md) 与 [资源边界](ASSET_BOUNDARY.md)。可复核的精简指标在 `reports/`，不含截图或逐图调试产物。

## 清晰卡阶矩阵

使用 122 个身份，覆盖 1–5 阶和四种屏幕分辨率（1280×720、1440×1080、1920×1080、2560×1440）；共 220 张清晰完整截图、2440 次卡片观察。身份与卡阶均为 2440/2440，零错读、零拒识和零多报；每个卡阶均为 488/488。分语言、稀有度和分辨率计数见 `reports/acceptance/clear-rank-matrix.json`。这项专项测试把等级固定为 Lv.1，因此不代表不同等级的准确率。

卡阶识别采用精灵模板匹配，不是独立的神经网络卡阶分类器。场景训练样本包含 1–5 阶；逐阶训练数量和本矩阵的测试结果分别见 `reports/training/rank-distribution.json` 与上面的专项报告。

## 独立整屏合成测试

权重和阈值冻结后评估 560 张普通截图、280 张压力截图。测试包含五种语言、多个列表参数视图、合法随机等级、独立分辨率与压缩配置。卡片身份和定位框 IoU≥0.5 才算识别正确；压力裁切可能导致卡片或字段拒识／未定位。

| 项目 | 普通：560 屏 | 压力：280 屏 |
|---|---:|---:|
| 身份正确／目标卡片 | 9673/9779（98.92%） | 3956/4531（87.31%） |
| 等级正确／可见目标 | 1518/1522（99.74%） | 597/688（86.77%） |
| 卡阶正确／可见目标 | 7249/7407（97.87%） | 2391/3281（72.87%） |
| 特训次数正确／可见目标 | 637/637（100%） | 238/279（85.30%） |
| 错误字段输出 | 0 | 0 |
| 隐藏字段输出 | 0 | 0 |
| 计分区域内多报 | 0 | 0 |

其余字段目标因拒识或未定位而未读出：普通截图中等级 3 次拒识、1 次未定位，卡阶 124 次拒识、34 次未定位；压力截图中等级 50 次拒识、41 次未定位，卡阶 481 次拒识、409 次未定位，特训 1 次拒识、40 次未定位。零误读只描述这些合成测试中已输出的值，不等于零漏读或对任意输入都正确。逐语言、分辨率、压缩和参数视图统计见 `reports/acceptance/synthetic-full-screen.json`。

测试数据清单覆盖十组、共 5056 张生成截图。文件哈希、完全重复、身份隔离、培养合法性和可见标签语义审计均通过；审计不证明合成图与真实客户端逐像素一致。摘要见 `reports/acceptance/synthetic-data-audit.json`。

## 未知身份与真实截图回归

未知身份开发检查从图库移除 17 个身份后，在 1258 次未知卡片观察中未误报为已知卡；7629 次已知卡观察中正确识别 7579 次。另有 8 张纯色／模糊背景没有卡片输出。原检查还记录 235 个未匹配到计分真值的预测（含需要另行分类的裁切区域），因此不声称对任意未知图像或背景都零误报。计数见 `reports/acceptance/unknown-card-results.json`。

十张真实截图只用于校准和回归，来自同一用户的一批 24 张成员卡和 3 张留影卡，不是独立真实用户测试：身份 156/156、可读等级 20/21、卡阶 120/120、特训 18/18；一个等级被拒识，没有错误字段或隐藏字段输出。局部被遮挡的字段保留未知。汇总见 `reports/acceptance/real-sample-regression.json`；原始图片及含本机路径的报告不随公开包发布。

渐隐、浮层或大面积遮挡可能让字段变成未知，也可能造成误读。此次只发布清晰完整画面上验证的策略；遇到遮挡请调整位置后重截，并检查或手工校对，不依赖模型还原被遮住的值。

## CPU 性能

Windows 10、Intel Core i5-12400F（主机 12 逻辑 CPU），扫描 10 张真实截图；每张热身一次，再分别测 5 次，共 50 次／配置。计时含定位和字段读取，不含图片解码及 HTTP。

| 指标 | 2 逻辑 CPU | 4 逻辑 CPU |
|---|---:|---:|
| 扫描中位数 | 1821.57 ms | 1661.27 ms |
| P95 | 2427.30 ms | 2900.11 ms |
| 最大值 | 2528.20 ms | 6893.82 ms |
| 进程内存 | 约 628 MB | 约 632 MB |

保留离群值，测试没有隔离主机其他负载，不据此推断 4 核一定更快。逐次结果、CPU 限制和代码指纹见 `reports/performance/`。
