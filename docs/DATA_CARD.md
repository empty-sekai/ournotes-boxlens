# Our Notes BoxLens 数据卡

训练与主要评估使用合成数据。真实图只用于回归，未作为可泛化准确率的独立测试集。用户截图不自动加入公开仓库或训练数据发布包。

稀有度覆盖、未覆盖的编队画面与卡面变体，以及遮挡口径见 [COVERAGE.md](COVERAGE.md)。不能将当前资源快照的身份覆盖表述为所有游戏 UI 风格全覆盖。

## 资源依据

游戏 APK 1.0.1-25 的 prefab、UI 精灵、语言字体规则及文本材质；129 张成员／留影卡的 master 快照与对应卡面（目录 SHA-256 `c6995ccac52fa98438eeca3cd82e375e6e417e64b5b0f3e91ecacfb5fee8647e`）。成员卡面使用 square 图按列表的竖向窗口等比填充裁切。五语言字体分别来自客户端规则，细节见 RESOURCES.md 和证据文件。

合成培养状态遵守 masterdata 的等级、觉醒、卡阶范围。显示模式区分 level、training、total、performance、technic、visual、hide；不可见字段真值为未知，潜在培养状态另存用于生成审计。

## 字段分布

两组整屏训练真值中可见等级共 59040 个：Lv.1 为 1061 个，Lv.2–20 为 21111 个，Lv.21–40 为 20593 个，Lv.41–60 为 12023 个，Lv.61–80 为 3963 个，Lv.81–90 为 289 个；1–90 每一级都出现。卡阶 1–5 在真值中各约 56600–57300 次，特训次数 1–5 各约 4600–4800 次。逐组计数见 `reports/training/scene-coverage.json`。

## 身份分割与泄漏审计

整屏训练与身份编码器的 ID 排除规则为 `id % 7 == 0`，成员／留影分别处理；129 个身份中保留 19 个编码器训练外身份，它们出现在所有开发和最终测试组中。参数与卡阶模型的初始化权重曾在全图库卡面上训练，采集降质裁块也使用全图库卡块，因此这里的“训练外身份”严格指身份编码器，不能扩展成所有网络都未见过相关像素。

同一玩家状态可出现在相邻截图，用于多图合并测试，因此卡片观察不是相互独立的真实用户样本。数据切分以生成配置和数据组为边界；真实统计外推不能直接使用合成样本数。每张合成图的真值都包含逐图 SHA-256，`bdon_vision.scenes verify` 检查哈希、完整性和真值格式。

## 真实性限制

- 背景为卡面模糊、噪声和渐变，或使用者提供的场景图；卡片 UI 使用原生资源。
- SDF 栅格化和抗锯齿为近似，未宣称所有设备像素一致。
- 能力／百分比视图中的 power 值用于干扰项，没有完整复现 native 战力计算；不将这些值列为目标输出。
- scenes-v2 数据由上一生成器版本产生，只能以真值哈希核对。
- 真实回归图共 8 张，来自同一玩家和设备，来源、玩家、设备多样性有限。
