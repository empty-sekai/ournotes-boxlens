# Our Notes BoxLens 数据卡

训练与主要评估使用合成数据。真实图只用于校准和回归，未作为可泛化准确率的独立测试集。用户截图不自动加入公开仓库或训练数据发布包。

稀有度／属性的实际训练与验证数量、未覆盖 BD／编队／卡面变体，以及真实图局部遮挡口径，见 [COVERAGE.md](COVERAGE.md)。不能将当前资源快照的身份覆盖表述为所有游戏 UI 风格全覆盖。

## 资源依据

游戏 APK 1.0.1-25 的 prefab、UI 精灵、语言字体规则及文本材质；122 张成员／留影图库及对应 masterdata。使用成员 square 图按列表的竖向窗口等比填充裁切。五语言字体分别来自客户端规则，细节见 RESOURCES.md 和证据文件。

合成培养状态遵守 masterdata 的等级、觉醒、卡阶范围。显示模式区分 level、training、total、performance、technic、visual、hide；不可见字段真值为未知，潜在培养状态另存用于生成审计。

## 数据规模和分割

| 数据组 | 用途 | 整屏数 | seed |
|---|---|---:|---:|
| scale-v6/train | 训练，等级视图，简中默认 | 2048 | 50021 |
| modes-v7/train | 训练，五语言、多模式 | 350 | 91703 |
| scale-v6/validation | 开发验证 | 512 | 60017 |
| modes-v7/validation | 开发验证，多语言多模式 | 140 | 92711 |
| scale-v6/stress | 开发压力测试 | 256 | 70019 |
| modes-v7/stress | 开发压力测试，多语言多模式 | 70 | 93713 |
| final-v9/validation | 阈值冻结后的新整屏测试 | 560 | 908271 |
| final-v9/stress | 阈值冻结后的新压力测试 | 280 | 708289 |

整屏合计 4216 张。训练 2398 张产生 37310 个完整裁块；开发普通验证 652 张产生 10278 个完整裁块。表中开发集曾用于诊断和阈值选择，不再称为最终未见测试。最后两组虽沿用数据目录名 final-v9，正式验收使用 v10 阈值。

此前还有 202000／30300 个等级预训练／验证裁块，以及 106000／21200 个多语言原生参数预训练／验证裁块。它们是不同阶段的字段数据，不能把数量简单累加后称为独立整屏截图数量。字段识别预训练覆盖 1–100 的数字字形；完整截图才检查每张卡的合法培养状态。

实际保存的整屏训练真值含 32938 个可见等级：Lv.1 为 643 个，Lv.2–20 为 11833 个，Lv.21–40 为 11416 个，Lv.41–60 为 6659 个，Lv.61–90 为 2387 个，合计覆盖 1–90 每一级。困难字段训练的 63600 个等级裁块覆盖 1–100，每级 576–709 个；其余字段裁块为其他／隐藏参数或特训类别。逐级计数见 `reports/training/level-distribution.json`。

清晰卡阶专项矩阵把等级固定为 Lv.1，是为独立检查 1–5 阶图标；该矩阵不是训练集，其等级成绩不能外推为其他等级的准确率。

整屏训练与身份编码器的 ID 排除规则为 `id % 7 == 0`，成员／留影分别处理；122 个身份中保留 17 个编码器训练外身份。字段预训练曾使用全图库底部图像作为随机文字背景，因此这里的“未见身份”严格指身份编码器，不能扩展成所有网络都未见过任何相关像素。普通／压力验证的屏幕分辨率列表和离散压缩质量值与训练不同，同时使用独立 seed。图片有多次 JPEG/WebP 压缩、缩放、模糊、UI 尺寸和滚动裁切。

## 关联性和泄漏审计

同一玩家状态可出现在相邻截图，用于多图合并测试，因此卡片观察不是相互独立的真实用户样本。数据切分以生成配置和数据组为边界；真实统计外推不能直接使用合成样本数。

8 组数据已完成文件哈希、重复图、训练 ID 排除、培养合法性和可见标签一致性审计，未发现错误。旧 v6/v7 真值文件没有逐图 SHA-256，审计读取实际图片重新计算，并明确记录此情况；v8 裁块构建也将全部实际图片字节纳入源数据指纹。新数据的真值直接包含逐图哈希。

## 真实性限制

- 背景为生成的模糊色块，不是完整游戏场景模拟；卡片 UI 使用原生资源。
- SDF 栅格化和抗锯齿为近似，未宣称所有设备像素一致。
- 能力／百分比视图中的 power 值用于干扰项，目前没有完整复现 native 战力计算；不将这些值列为目标输出。
- 原训练与现行多语言渲染器有版本演进；复现具体 checkpoint 要使用保存的阶段源码与资源清单，不应用最新生成器冒充原始逐字节数据。
- 历史整屏合成在拼接时按卡框裁切，截掉了部分外伸属性／卡阶图标。现行生成器改为保留原生透明边距，完整卡阶矩阵使用修正后的拼接。历史训练和测试报告保留其原始输入条件，不改写成完整图标测试；本次未因此重训模型。
- 真实回归图共 10 张，覆盖同一批 24 成员／3 留影及不同参数视图，来源、玩家、设备多样性有限。
