# Our Notes BoxLens 模型卡

v0.1.0 使用冻结的编码器和字段模型权重，并包含留影显示窗口坐标修正；权重选择分别为编码器追加微调第 2400 步、字段困难采集训练第 5500 步，字段阈值保持 0.995。修正后另行完成 840 张独立整屏最终测试。目标输入是清晰列表截图；遮挡可能误读或拒识，不追加遮挡训练或遮挡专项推理规则。完整结果见 EVALUATION.md，公开内容边界见 ASSET_BOUNDARY.md。

## 用途和输出

成员／留影列表截图导入：定位卡片、检索 master ID，读取可见等级、卡阶与成员特训次数。不可见或不确定字段输出未知，跨图分歧保留冲突。模型不判断玩家未展示的收藏，不从卡面推测培养值。

## 两个神经网络

| 文件 | 输入 | 输出 | 架构 |
|---|---|---|---|
| `encoder.onnx`／`encoder.pt` | float32 RGB、NCHW、`N×3×160×128`、0–1 | L2 归一化的 128 维向量 | MobileNetV3-Small features、固定池化和线性投影；内部执行 ImageNet mean/std 归一化 |
| `fields.onnx`／`fields.pt` | float32 RGB、NCHW、`N×3×56×144`、0–1 | 106 个未归一化 logits | 24/48/64/96 通道卷积、池化、线性分类头 |

字段类别：0 为其他／隐藏参数；1–100 为等级；101–105 为特训次数 1–5。ONNX opset 17，batch 维可变。字段 softmax 接收阈值为 0.995、第一二候选差值至少 0.5。得分不是经过校准的概率。

权重不独立承担全部识别。RootSIFT/RANSAC 定位后通过卡面像素核验；弱纹理网格位置由神经图库和像素匹配共同确认。卡阶用原始精灵与卡面背景合成匹配，检查图标是否完整可见。等级进一步检查 masterdata 上限。

卡阶模板接受条件为匹配分数至少 0.78、前两名分差至少 0.007；0 阶模板用于拒绝非已拥有状态，不输出合法卡阶 0。图标越界或分数不足时返回未知。模板分数也不是校准概率。

读取位置修正保持选定权重和阈值不变：成员参考图已按 UI 比例规范化，留影参考图仍是完整原图，因此先将留影匹配框转换成 314×172 的等比填充显示窗口，再读取参数／卡阶；背景匹配仍按完整原图坐标采样。否则 512×288 留影图的上下裁切量会变成随分辨率放大的读取偏差。本修正不引入新的训练，也不降低接受阈值。

## 实际训练链

| 阶段 | 初始化 | 数据／步数 | 优化器 |
|---|---|---|---|
| encoder v4 | torchvision MobileNetV3-Small ImageNet 权重 | 训练身份卡面增强，1200 steps，batch 128，seed 7319 | AdamW，lr 0.0004、weight_decay 0.0001 |
| level v6 | 随机初始化，seed 8317 | 202000 合成等级裁块；12000 steps，batch 512 | AdamW，lr 0.001 |
| fields v7 | level v6，扩展至 106 类 | 106000 多语言原生字段裁块；8000 steps，batch 512，seed 90011 | AdamW，lr 0.0003、weight_decay 0.0001 |
| encoder v8 | encoder v4 | 2398 张训练整屏中的 37310 个完整卡片裁块；2400 steps，batch 128，seed 71933 | AdamW，lr 0.00012、weight_decay 0.0001 |
| fields v8 | fields v7 | 同批场景字段裁块，约三分之一 batch 回放原生字段预训练集；2400 steps，batch 512，seed 90011 | AdamW，lr 0.0003、weight_decay 0.0001 |
| encoder v11 | encoder v8 | 相同场景数据追加 2400 steps，batch 128，每 300 步评估 | 新建 AdamW，lr 0.00012、weight_decay 0.0001 |
| fields v12 | fields v8 | 106000 个按截图采集顺序生成的困难字段；回放场景字段，训练 8000 steps，batch 512，每 500 步评估；选用第 5500 步 | 新建 AdamW，lr 0.0003、weight_decay 0.0001 |

候选仅依据开发集选择：普通可见字段正确数不得低于原模型、普通误读为零、压力集错误和隐藏字段输出不高于原模型，再在符合条件的 checkpoint 中提高压力集正确覆盖数。第 8000 步虽接受更多困难字段，错误也更多，因此未采用。选择规则及权重哈希保存在 `selection.json`；最终测试指标未用于选择。

编码器训练排除 `id % 7 == 0` 的 17 个身份，训练查询及参考分支不使用其卡面。验证时才将新卡向量加入图库。固定模型权重可通过 catalog／素材／索引更新接入新卡。

实际训练机器为用户提供的 ModelScope DSW-AMD，框架报告显存 191.69 GiB，设备名称字符串为空，因此不推断具体 GPU 型号。实际环境：Python 3.12.13、torch 2.12.0+git6bbd260、torchvision 0.27.1+df56172、HIP 7.2.53211、Pillow 12.3.0、numpy 2.3.5、ONNX 1.22.0、ONNX Runtime 1.30.0。公开这些实际版本，不将自定义镜像版本写成普通 PyPI 通用安装组合。

设置随机种子用于数据和训练复现；未宣称跨 GPU、驱动及框架实现的训练权重逐字节确定。发布 checkpoint 哈希用于精确确认使用的权重。

## 验证边界

完整指标见最终评估卡及 JSON 报告。场景裁块验证上的 100% 分类结果不能代替完整截图定位／裁切后的准确率。真实 10 张图属于校准和回归，不能据此宣称跨玩家真实分布准确率。

低分辨率、重压缩、模糊和裁切会降低覆盖率；未知字段需要校对。未知卡拒识测试只覆盖测试集中移除图库的身份及指定负样本，不保证所有未知图像无误报。布局或客户端字体变化需要重新验证。
