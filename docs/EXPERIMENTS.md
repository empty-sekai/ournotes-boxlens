# 训练收敛与数据改进

## 同一批数据上的追加训练

编码器和字段模型分别从原 checkpoint 用相同训练数据追加 2400 steps；优化器状态重新初始化为 AdamW，因此不把前后 loss 当作同一条连续曲线。

| 指标 | 初始模型 | 追加训练后 |
|---|---:|---:|
| 字段模型：普通裁块 top-1 | 10278/10278 | 10278/10278 |
| 字段模型：困难裁块高置信且正确 | 2836/4058 | 2873/4058 |
| 字段模型：困难裁块错误 | 1 | 1 |
| 字段模型：困难裁块交叉熵 | 2.53904 | 2.68795 |
| 编码器：困难裁块 top-1 | 4651/4766 | 4706/4766 |
| 编码器：高置信检索错误 | 10 | 1 |
| 编码器：训练外身份困难裁块 top-1 | 642/655 | 642/655 |

字段困难集的 loss 在追加 600 steps 时最低，之后上升；正确高置信覆盖率仅从 69.89% 升至 70.80%。这表明只对同一批数据继续拟合，字段模型收益有限。

## 更贴近屏幕采集的合成数据

旧的困难裁块路径在放大后才压缩，与真实流程中截图先缩小／压缩、再被识别器放大的顺序不同。修正数据采集顺序后，生成 106000 个训练裁块和 21200 个独立验证裁块：先在低分辨率施加模糊及多轮 JPEG/WebP 压缩、改变编码块相位，再放大到模型输入尺寸。训练集和验证集使用不同采集配置；训练混入整屏裁块回放。

从同一初始字段权重训练 8000 steps，每 500 steps 用普通与压力开发集选模。第 5500 步普通可见字段正确 8671 个、错误 0 个；压力字段正确 3245 个、错误 1 个。第 8000 步压力正确数升至 3281，但误读增至 4 次、普通集正确数降至 8659，因此没有采用最后一步。按事先确定的选择规则，发布第 5500 步权重。

冻结候选后，在独立困难字段验证集的 16960 个数值目标中，初始模型正确 12036 个、误读 3 个；候选正确 15148 个、误读 4 个，覆盖率从 70.97% 升到 89.32%。两个模型在其他／隐藏参数负例上都没有输出数值。这是字段裁块结果，不代表整屏准确率；整屏独立测试见 [EVALUATION.md](EVALUATION.md)。开发曲线和裁块验证摘要见 `reports/training/`。
