# 公开内容与游戏资源边界

本项目自身的源码、文档和发布的训练权重采用 MIT；第三方许可和预训练来源见 THIRD_PARTY_NOTICES.md。MIT 不授予任何游戏资源或商标的权利。

公开仓库及 GitHub Release 附件包括：识别和训练源码、合成／验证工具、JSON Schema、模型 ONNX／PyTorch 权重、模型清单、资源文件哈希、统计报告及复现步骤。

以下内容不随仓库、wheel、源码包或权重包分发：

- 游戏卡面、缩略图、头像、UI 精灵、图集、字体／glyph atlas。
- APK、AssetBundle、完整 prefab 导出、masterdata 正文。
- 用户截图，以及含游戏画面的合成训练／验证截图或裁块。
- 原始反编译 C／IL2CPP 导出、私有解密配置、密钥、账号凭据。
- 含游戏资源的一键运行包和图库向量缓存。

使用者在本地自行准备相应资源，并按 RESOURCES.md 组装数据目录。发布权重不替代图库和原生 UI 资源；新卡接入仍需使用者更新自己的 masterdata／素材并重建图库。

公开资源哈希用于确认实验输入，语言字体名称和接口事实用于说明兼容范围；它们不包含字体文件、资源正文或可重建游戏图像的编码。模型权重与直接分发训练图像是不同交付项；本项目不声称对训练使用的游戏美术或文字拥有版权。

公开构建使用明确的文件清单，拒绝图片、字体、APK、资源目录、反编译代码和私有配置。构建后的 source／wheel／weights 附件均需再次检查文件清单。
